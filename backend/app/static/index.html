How To Use Multy-Bt

1. Start a task
Create a task on the left. If it touches code, add the project folder.

2. Prepare a safe copy
Use Prepare Safe Copy before asking a helper to modify a codebase.

3. Start the first helper turn
Use Send Task on the right to launch a full turn for Codex or Claude.

4. Talk inside the task
Use Conversation for notes, questions, decisions, and follow-up instructions.

5. Know the difference
Send Message only records a message. Send And Ask Helper records the message and immediately starts a helper run.

6. Transfer work between helpers
Use Transfer under an agent reply when you want the next helper to continue from that result.

7. Track progress
Use Task Stage to move work from Ready to In Progress, Needs Review, and Done.
